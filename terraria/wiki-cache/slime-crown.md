# Slime Crown

Source: https://terraria.wiki.gg/wiki/Slime_Crown
Fetched: 2026-08-20T08:16:54.784Z

---

The Slime Crown is a boss-summoning item that summons King Slime when used. It can be used in any biome at any time.
When thrown into Shimmer, the Slime Crown is consumed and the Slime Rain event begins immediately. If the event is already in progress, then the item merely sinks to the bottom of the Shimmer like all other non-decraftable items.
