# Classes, elements and roles

## Direction

Start with approachable **Warrior, Ranger and Wizard** identities: melee, ranged, magic. Later islands unlock additional classes. Start worldbuilding with **Fire, Water, Earth and Air**. A player's class, element, starter and deck should combine into distinct builds.

Class describes how one fights; element describes the magic; the starter is a build centerpiece; tank/support/damage describes the contribution a build makes to a team. These are separate axes. Fire Warrior and Fire Wizard should not be mechanically identical. Do not equate “Water” with a mandatory healer or “Warrior” with the only tank.

## Working identities — hypotheses

| Element | Candidate verbs | Mythic/domain prompt |
| --- | --- | --- |
| Fire | Pressure, burn, momentum | Flame being / volcanic domain |
| Water | Sustain, flow, control | Ocean being / tidal domain |
| Earth | Protect, endure, fortify | Burrowing guardian / deep domain |
| Air | Mobility, tempo, circulation | Sky being / high domain |

These are design prompts; no weakness chart, resistance system or automatic steam/lightning/metal reaction is settled. Elemental mythic creatures and monarchs are desired; actual species and identities remain original work to develop.

## Compatibility

The existing engine has thirteen non-neutral classes, including Fighter, Ranger and Wizard. Starter Warrior uses the existing `fighter` identifier and hero power; it is a presentation alias, not a destructive rename. Existing `storm` cards continue to load alongside new `earth` and `air`. No old save is silently converted. The starter slice exposes the three initial classes and four elements; later classes remain available in practice.

## Open
