# V1 scope

## Distinguish three milestones

**Now: local vertical slice.** One small home map, movement, contextual NPC/resource/rest interactions, one encounter using the existing duel, exactly five starting cards, a Legendary placeholder, outcome/reward return and content structures for classes/elements/cards. Placeholder art is intentional.

**Candidate V1: first island episode.** A complete local story arc: relationships → learning/collection → crisis → satisfying encounter/payoff → departure hook. Adam proposed shipping the first island like a manga chapter. This is the preferred planning hypothesis, not a release date or final acceptance of every feature discussed.

**First arc: five islands / about 50 levels.** A content roadmap that may be delivered over multiple releases, not a requirement that all five islands ship before a playable build.

## Not required for the immediate slice

Online co-op/PvP, accounts, text/voice, player market, packs, crafting ledger, mounts, gear progression, full invasion cinematic, XP/rank ladder, fizzle/evolution, multiple playable islands or polished assets. Preserve those directions in docs rather than pretending buttons implement them.

The assistant once proposed three classes, four legendaries, 30–50 cards, two-player co-op, one dungeon and one boss for V1. That was not confirmed as a production commitment. The local slice can expose three existing hero powers and four starter looks cheaply without committing to twelve bespoke class-element campaigns.

## Acceptance for this scaffold

- Launch the starter island from the existing client while keeping Ember Reach available.
- Move around land, interact near landmarks and enter the encounter deliberately.
- Start with a selected starter Legendary plus four supporting cards and approximately 30 HP.
- Use the real engine for mana, minions, spells, enemy AI, victory and defeat.
- Return with an honest result; victory awards once, defeat does not award; rest and replay work.
- Existing engine tests and type/build checks pass; test slice data and outcome invariants.

## Next human test

Try the route without instructions beyond the visible controls. Is the first encounter understandable? Does the starter feel like a companion? Is home worth protecting? Does five-card fatigue feel appropriate? Record one concrete friction before expanding scope. This is not a release or deployment authorization.
